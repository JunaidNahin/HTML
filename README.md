<li></li> -> li is listed items which is used to list items under unordered or orderder list

example: 

***unordered list***
<ul>
  <li>fish</li>
  <li>chicken</li>
</ul>

it represents like: +fish
                    +chicken

***ordered list***
<ol>
  <li>morning</li>
  <li>noon</li>
</ol>

it represents like: 1.morning
                    2.noon
